OpenAI-compatible image-to-video API

This gateway exposes an OpenAI-style API for the Miricanvas image-to-video model. Authentication uses an API key (create one in the console). All requests and responses are JSON.

Base URL-
Modelmiricanvas-image-to-video
Auth headerAuthorization: Bearer <api-key>

POST /v1/video/generations submit a job

Accepts a source image and a motion prompt. Returns a task immediately; the video is produced asynchronously.

Request body

{
  "model": "miricanvas-image-to-video",
  "prompt": "Slow camera push-in, gentle parallax, cinematic light",
  "image": "https://example.com/photo.jpg"
}

The image field also accepts a raw base64 string or a data:image/...;base64,... URL. image_url, input_image and images[0] are accepted as aliases.

Response

{
  "id": "3f1c…",
  "status": "queued",
  "progress": 0,
  "video_url": null,
  "error": null,
  "created": 1710000000
}

curl

curl -X POST "$BASE/v1/video/generations" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"gentle parallax","image":"https://example.com/photo.jpg"}'

GET /v1/video/generations/{id} poll a job

Poll until status is completed (or failed). When complete, video_url holds the downloadable MP4.

{
  "id": "3f1c…",
  "status": "completed",
  "progress": 100,
  "video_url": "https://…/output.mp4",
  "error": null,
  "created": 1710000000
}

curl

curl "$BASE/v1/video/generations/3f1c…" \
  -H "Authorization: Bearer $API_KEY"

GET /v1/models list models

Public — no API key required.

{
  "object": "list",
  "data": [{ "id": "miricanvas-image-to-video", "object": "model" }]
}

GET /health service status

Public health probe with live stats and device-ledger capacity.

{
  "status": "ok",
  "requests": 12,
  "tasks_completed": 9,
  "errors": 1,
  "devices": { "today_devices": 5, "remaining_today": 1, "…": "…" },
  "version": "2.0.0"
}
